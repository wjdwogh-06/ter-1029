# 초승달섬 전초기지 (ter-1029)

롱빈터(Longvinter) 느낌의 3D 모바일 브라우저 생존 게임입니다.
빌드 과정이 없습니다. 파일을 그대로 열면 실행됩니다.

- 맵 1000×1000, 초승달 본섬 + 동북섬 + 작은 섬 7개, 모든 플레이어가 같은 맵
- 채집, 제작, 건설, 낚시, 밤 습격, 신비한 몹(바위 골렘, 나무 골렘, 악령, 식인 덩굴)
- 항구마을 상인(텐트·손도끼·낚싯대·보관 상자), 텐트 내부 공간, 머리 위 말풍선 채팅
- 항구 8곳(가운데는 항구마을), 보급 지점 14곳, 바다 등대 8곳
- 멀티플레이 서버 뼈대(최대 100명, PvP) 포함. 아직 배포하지 않음

## 실행

**혼자 하기 (정적 파일)**
```
python3 -m http.server 8765      # 그다음 http://localhost:8765
```
`index.html`을 더블클릭해서 열면 안 됩니다(`assets/*.json`을 fetch 하므로 http로 열어야 함).

**멀티 서버와 같이**
```
npm start                        # = server 폴더 npm install 후 node server/server.js
```
http://localhost:8080 에서 게임과 서버가 함께 열립니다. 자세한 내용은 `server/README.md`.

**GitHub Pages**: 저장소가 비공개면 유료 플랜이 필요합니다. 공개로 바꾸면 Settings → Pages → main 브랜치 루트로 바로 됩니다(혼자 하기 모드).

## 폴더

| 경로 | 내용 |
|---|---|
| `index.html` | 화면 뼈대, CSS, 스크립트 로드 순서 |
| `js/core.js` | 상수, 맵 생성(높이, 섬, 강, 항구·보급·등대 좌표), 아이템·무기·건물·퀘스트 데이터, 개발자 모드 상태 |
| `js/world.js` | 렌더러, 절차적 모델, 지형 메시, 나무·바위 배치, 구조물(addStruct), 이펙트, 환경 |
| `js/actors.js` | 캐릭터·몹, 이동/충돌, 상호작용, 스폰, 습격, 포탑·함정 |
| `js/water.js` | 물 셰이더, 헤엄, 낚시 |
| `js/ports.js` | 항구 8곳(부두, 배, 항구마을 건물) |
| `js/dress.js` | 나무 모델, 바닥 장식(풀·꽃·돌), 보급 지점 |
| `js/interior.js` | 텐트 내부 공간 |
| `js/chat.js` | 채팅 입력창과 머리 위 말풍선 |
| `js/ui.js` | HUD, 패널, 지도, 개발자 모드 UI, 부팅(boot)과 메인 루프(tick) |
| `js/net.js` | 멀티 클라이언트(서버에서 열었을 때만 켜짐) |
| `server/` | Node + ws 서버, 봇 부하 테스트 |
| `tools/` | 헤드리스 크롬 테스트 |
| `assets/` | KayKit 모델 묶음(base64 JSON) |
