# 초승달섬 전초기지 — 멀티 서버

## 실행
```
cd server
npm install
npm start          # http://localhost:8080 에서 게임과 서버가 같이 열립니다
```
환경 변수: `PORT`(기본 8080), `MAXP`(정원, 기본 100), `DATA`(저장 파일 경로, 기본 server/world.json)

## 구조
- `server.js` 서버 한 개가 월드 하나(최대 100명)를 맡고, 게임 파일도 같이 내려줍니다.
- `../js/core.js` 맵·무기·건물 규칙. 서버와 클라이언트가 같은 파일을 씁니다.
- `../js/net.js` 클라이언트 쪽 접속 코드. 서버에서 열었을 때만 켜집니다.
- `bots.js` 부하 시험용 가짜 접속자: `node bots.js 100 ws://localhost:8080/ws`
- `/status` 접속자 수, 전송량, CPU, 메모리 확인
